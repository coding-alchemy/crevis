# 安全、治理与可观测性模块

> 上级文档：[Crevis 项目架构规格说明](../architecture.md)

## 1. 模块目标

本模块定义跨所有业务模块的安全、权限、素材授权、日志、指标、追踪、成本和保留策略。安全规则必须落实在服务端和基础设施层，不能只依赖前端约束。

## 2. 身份与授权

- 所有业务实体带 `workspace_id`；
- 基础角色为 `owner/editor/viewer`；
- Repository 查询默认注入 workspace 条件；
- Worker 从 NodeRun/Task 解析工作区，不能接受队列消息中的任意工作区覆盖；
- 管理员跨空间操作必须产生特殊审计事件；
- 下载签名 URL 只向有权限的请求者签发。

即使第一版为单用户，表结构和服务接口也保留 `workspace_id`，防止后续迁移破坏数据边界。

## 3. 密钥与凭证

- 供应商密钥通过环境变量或密钥管理服务注入；
- 数据库只保存 credential 引用、供应商和脱敏标识；
- 日志、异常、任务快照和模型原始响应统一脱敏；
- 密钥按工作区/环境隔离并支持轮换；
- webhook secret 与 API Key 分开管理；
- 前端永不接收供应商密钥。

配置文件只保存非敏感运行参数。示例配置使用占位符，不能提交真实 key。

## 4. 文件和 URL 安全

### 4.1 上传

- 使用魔数和解析器校验，不信任扩展名或 Content-Type；
- 限制文件大小、图片像素、视频时长、轨道数和解压比例；
- 临时目录隔离，文件名不参与 shell 命令；
- 可选接入恶意文件扫描；
- 上传完成前素材不可被工作流引用。

### 4.2 URL 导入

- 只允许 HTTP(S)；
- 阻止回环、私网、链路本地、云元数据地址和非标准跳转；
- 每次 DNS 解析和重定向后复核目标；
- 设置连接/读取超时、最大跳转和最大字节数；
- 下载后重新校验真实 MIME 和媒体可读性。

### 4.3 媒体处理

- FFmpeg 使用参数数组或受控执行计划；
- 不允许用户注入任意滤镜、协议或 shell 片段；
- Worker 使用资源上限和非特权账户；
- 禁用不需要的网络协议和本地路径访问；
- 临时文件按任务隔离并自动清理。

## 5. 模型数据治理

- 每个供应商记录数据区域、保留、训练使用和内容策略；
- Workspace 可限制某类素材发送到某供应商；
- Prompt/模型调用附件按敏感级别设访问和保留期；
- 人物肖像、声音和音乐记录来源、授权范围、到期时间；
- 授权到期后阻止新生成，但保留历史审计和已生成结果的处理策略；
- 敏感内容检查结果与用户决策留痕。

## 6. 删除与保留

- 业务删除默认为软删除/归档；
- 被 Project、Revision、Run、Timeline 或 AssetRelation 引用的版本不能立即物理删除；
- 临时上传、供应商临时副本和 Worker 临时目录设置短生命周期；
- 大型原始响应和 FFmpeg 日志设置独立保留期；
- 物理删除由后台任务执行并写审计事件；
- 法务保留可覆盖普通清理策略。

## 7. 审计

追加式审计事件至少记录：

- 操作者/服务身份；
- workspace、资源类型和资源 ID；
- 动作、前后版本或变更摘要；
- 来源 IP/客户端、trace id 和时间；
- 审批、密钥配置、权限、删除和供应商切换等高价值操作。

审计日志与普通应用日志分开保留，应用用户不能修改。

## 8. 追踪与日志

每个 HTTP 请求、WorkflowRun、NodeRun、GenerationAttempt、MediaTask 和 RenderTask 使用关联 trace id。

结构化日志字段建议：

```text
timestamp, level, service, environment,
trace_id, workspace_id, project_id,
workflow_run_id, node_run_id, task_id, attempt_id,
provider, model, error_code, duration_ms
```

日志只保存 ID 和摘要。大型模型响应、媒体命令日志和诊断文件放对象存储并通过权限控制访问。

## 9. 指标

### 9.1 系统

- API 延迟、错误率和并发；
- 队列长度、最老消息年龄和消费速率；
- Worker 活跃数、租约过期和 heartbeat；
- PostgreSQL 连接、事务冲突和慢查询；
- 对象存储请求错误和容量。

### 9.2 工作流与供应商

- 节点等待/执行时长、成功率、重试率；
- WorkflowRun 完成时长和失败节点分布；
- 供应商提交延迟、429/5xx、轮询和回调延迟；
- 结果搬运失败率；
- 人工审批等待和候选拒绝率。

### 9.3 媒体与成本

- FFmpeg 失败率、转码倍率和输出规格；
- 对象存储原始/派生/临时容量；
- 每模型调用次数、token/点数和费用；
- 每项目、分镜、成功视频秒的成本；
- 预算使用率和超限阻止次数。

## 10. 告警

至少覆盖：

- 队列持续积压；
- 大量租约过期或 Worker 消失；
- 供应商 429/5xx、认证或余额异常；
- `submitting`/`result_pending` 卡住；
- webhook 验签失败突增；
- 对象存储/数据库不可用；
- 磁盘临时区接近上限；
- 单项目费用或调用量异常；
- 日志脱敏检测发现疑似密钥。

告警必须指向可查询的任务/运行和操作手册，而不只发送错误字符串。

## 11. 成本控制

- WorkflowRun 可配置预算和优先级；
- 提交前做模型费用估算和配额校验；
- 记录估算费用与供应商实际费用；
- 重试、用户新候选和质量重生成分别计数；
- 达预算阈值时暂停运行并进入人工确认；
- 供应商路由可考虑成本，但实际模型必须留痕。

## 12. 验收标准

- 不同 Workspace 无法互相查询或下载素材；
- 密钥不进入数据库业务字段、日志、附件和前端；
- 上传、URL 导入和 FFmpeg 执行具备输入安全控制；
- 人物、声音和音乐授权可查询并限制新使用；
- 任意失败可通过 trace id 串联 API、节点、attempt 和 Worker 日志；
- 核心队列、供应商、媒体和成本指标可观测；
- 高风险操作和删除有不可修改审计记录；
- 达预算阈值时能暂停而不是继续无限生成。
